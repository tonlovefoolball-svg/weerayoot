ไฟล์ตั้งค่าเว็บไซต์

ไฟล์ที่แนบมาเป็นการตั้งค่า Netlify สำหรับเผยแพร่เว็บไซต์ ยังไม่ใช่ตัวเว็บไซต์ จึงไม่มีหน้าแอปให้ใช้งานจากไฟล์นี้เพียงไฟล์เดียว

เนื้อหาไฟล์

[build]
  publish = "."

[[headers]]
  for = "/sw.js"
  [headers.values]
    Cache-Control = "public, max-age=0, must-revalidate"
    Service-Worker-Allowed = "/"

[[headers]]
  for = "/manifest.json"
  [headers.values]
    Content-Type = "application/manifest+json"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200

ถ้าต้องการเปิดแอปบนมือถือ

ต้องมีไฟล์ index.html ของแอปด้วย แล้วนำไปเผยแพร่พร้อม netlify.toml จึงจะได้ลิงก์สำหรับเปิดในเบราว์เซอร์มือถือ หากส่งไฟล์เว็บส่วนที่เหลือมา ผมจะปรับหน้าจอและการใช้งานให้เหมาะกับมือถือได้

หน้านี้ใช้เปิดดูการตั้งค่าได้แม้ไม่ได้เชื่อมต่ออินเทอร์เน็ต
